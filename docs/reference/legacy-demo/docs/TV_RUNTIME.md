# District TV Runtime

## Autonomous show loop

```text
Observe audience + world + task events
        ↓
Producer chooses next beat
        ↓
Writer creates dialogue / action
        ↓
Character agents respond in personality
        ↓
Director chooses camera / animation / music
        ↓
TTS + realtime renderer
        ↓
OBS / WebRTC / stream output
        ↓
Update durable world memory
        ↺
```

## Roles

- **Producer Agent** — prevents dead air and injects useful events.
- **Writer Agent** — dialogue and short scene beats.
- **Director Agent** — camera, movement, transitions and pacing.
- **Character Agents** — persistent identity, memory and relationships.
- **Audience Agent** — filters worthwhile viewer messages.
- **World Agent** — maintains facts, locations, props and unresolved story events.
